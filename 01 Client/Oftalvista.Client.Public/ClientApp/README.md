# Oftalvista completo final

Proyecto Angular 17 standalone con archivos separados por componente.

## Incluye
- environments (dev y prod)
- app.config.ts
- app.routes.ts
- core/models
- core/services
- guard de autenticación
- interceptors
- módulos: auth, dashboard, especialidad, usuario, médico, paciente, agenda médica, cita, pago, historial, recordatorio, prototipos
- separación por archivos `ts + html + scss`

## Instalación
```bash
npm install
ng serve
```
